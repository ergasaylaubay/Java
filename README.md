Wolt Kazakhstan — Тағамға тапсырыс беру және жеткізу жүйесі
1. Жоба туралы

Бұл жоба Wolt Kazakhstan ұйымының тағамға тапсырыс беру және жеткізу бизнес-процесін зерттеуге арналған. Жобаның мақсаты — ұйым туралы ашық дереккөздерді зерттеу және Java бағдарламалау тілі арқылы тағамға тапсырыс беру мен жеткізуді басқарудың жеңілдетілген жүйесін жобалау.

Жоба тек ашық дереккөздерге негізделеді. Компанияның ішкі деректерін пайдалану немесе оның нақты ақпараттық жүйесін толық қайталау көзделмейді.

9. Объектіге бағытталған бағдарламалау принциптері
Инкапсуляция (Encapsulation) — объектінің ішкі деректерін қорғау және оларға әдістер арқылы қол жеткізу.
Абстракция (Abstraction) — жүйенің маңызды әрекеттерін бөліп көрсету және күрделі іске асыру бөлшектерін жасыру.
Мұрагерлік (Inheritance) — ортақ қасиеттері бар кластар арасында мұрагерлік байланысын қолдану қажет болған жағдайда пайдалану.
Полиморфизм (Polymorphism) — ортақ әрекеттерді әртүрлі кластарда әртүрлі жүзеге асыру қажет болған жағдайда қолдану.

Бұл принциптер жүйенің құрылымын түсінікті әрі кеңейтуге ыңғайлы ету үшін қолданылады.
